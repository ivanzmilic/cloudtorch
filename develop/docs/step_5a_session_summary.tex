\section{Lessons learned}
\begin{itemize}
\item \textbf{``Small in loss'' $\ne$ ``harmless.''} A 1--3\% penalty dominates a weakly-constrained (near-null) direction: the fixed background owns the line wings, so the data barely pulls on \co{vlos}, and any appreciable smoothness/hinge flattens it. Regularise weakly-constrained parameters \emph{only} as a backstop.
\item \textbf{No strong-reg sweet spot here:} reg trades $\sim$monotonically against \emph{both} $\chi^2$ and velocity structure. The fix is a gentler penalty, or a robust/far-outer hinge that clips outliers \emph{without} flattening.
\item \textbf{Activation design is physics.} Identity for signed/unbounded \co{vlos} $+$ a soft outer hinge is correct; bounded transforms (\co{S} sigmoid, \co{dtau}/\co{dv} softplus) only where a real physical bound exists; \co{SiLU} hidden units stay (smoothness reg needs a $C^\infty$ double-backward --- \co{ReLU} would be degenerate).
\item \textbf{Architecture:} prefer \emph{wide} over \emph{deep} for a Fourier-feature field --- the random features already supply the frequencies, so depth (no residuals here) mostly costs conditioning.
\item \textbf{Optimisation:} the explicit autograd reg slows convergence; \textbf{minibatch $+$ higher \co{LR}} makes the full 482k-pixel cube tractable in $\sim$2\,min.
\end{itemize}
